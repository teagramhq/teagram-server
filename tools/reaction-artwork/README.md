# Reaction artwork

From the repository root, run `./tools/reaction-artwork/generate.sh` to regenerate the static WebP and TGS assets from Twemoji v14.0.2. The script verifies the upstream commit and uses the pinned SVG-to-Lottie and WebP converter dependencies.

Generation requires Git, Node.js with npm, and Rust 1.85 or newer with Cargo.
